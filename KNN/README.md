#  K-Nearest Neighbors (KNN) Project

##  Overview
In this project, I implemented the KNN algorithm for a classification task as part of my learning.  
It helped me understand distance-based models and the importance of feature scaling.

---

##  Dataset
Dataset is sourced from Kaggle (Iris Dataset).  


---

##  Steps
- Data Loading & Understanding  
- Data Visualization  
- Feature Selection  
- Train-Test Split  
- Feature Scaling  
- Model Training (KNN)  
- Prediction & Evaluation
- Cross Validation

---

## Tools
Python, Pandas, NumPy, Seaborn, Matplotlib, Scikit-learn
